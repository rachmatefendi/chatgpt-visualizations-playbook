# Ready-to-Use Prompts

The [Quick Prompt Library](quick-start.md) offers reusable `@Visualize` prompts across financial analysis, workflow simulation, SaaS metrics, logistics and educational demonstrations.

Replace bracketed placeholders with supplied, permitted data. The output should be independently validated; no prompt guarantees compatibility, live connections, stable UI controls or a specific product rendering.

For a customized brief, use [the prompt template](../templates/prompt-base.md). For domain-specific acceptance tests, use the [12 use cases](../use-cases/README.md).
