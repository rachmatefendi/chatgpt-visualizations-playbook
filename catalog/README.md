# Component Evidence Catalog

The CSV [component-evidence.csv](component-evidence.csv) contains **43 catalog entries**. It is a research and design inventory—not a callable OpenAI API schema.

| Tier | Meaning |
|---|---|
| `V` | Format or interaction explicitly documented for ChatGPT Visualizations |
| `K` | Named UI component documented by ChatKit, a separate developer surface |
| `P` | A generic/custom interface design pattern or visualization candidate |

Read [Evidence Discipline](../docs/01-scope-and-evidence.md) and [UI Component Guide](../docs/03-ui-components.md) before using component entries to claim product support.

CSV columns: `element`, `category`, `evidence_tier`, `basis`, `recommended_use`. Data is editorial and may need revalidation after documentation changes.
