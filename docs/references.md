## Citation and revalidation rules

- Prefer exact published documentation over inference from demo visuals.
- A named ChatKit component is always tier K, regardless of similar-looking Visualizations UI.
- An illustrative layout remains tier P until primary evidence explicitly supports a more specific claim.
- If source content changes, capture the change date, impacted section, evidence tier and live-test status separately.
- Do not imply that source consultation is operational validation on the target account, or that references transfer source copyright.
