## Licensing decision gate

The author should explicitly determine whether the intended distribution is:

1. **Private/internal reference:** retain all rights reserved; restrict visibility accordingly.
2. **Publicly readable with restricted reuse:** retain all rights reserved; explain acceptable use or permissions separately.
3. **Public with open-content permission:** select an explicit documentation license (for example, CC BY 4.0) after reviewing terms and attribution conditions. Software examples, if any, may require separate treatment.

Do not add MIT, Apache, Creative Commons, or any other license without the author's explicit selection. This file is not legal advice.
